# Students Training_ egister

    # Ce projet est un système d'enregistrement des étudiants pour des programmes de formation.
    # Il permet de gérer les informations des étudiants, les programmes de formation disponibles,
    # et d'associer les étudiants à des formations spécifiques. Les données sont sauvegardées
    # dans un fichier JSON pour une persistance des enregistrements.
